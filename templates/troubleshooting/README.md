# Troubleshooting templates

These are blank reusable record shapes. Copy them into an approved local
working area when a future workflow is ready to handle client-specific work.
Do not put client details in this repository.

Every template starts with `required_fields`. The local validator uses that
list to reject a record that leaves out a required field. A result may say
`passed` only when it includes a check method, evidence reference, checker, and
check date.
